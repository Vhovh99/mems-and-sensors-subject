# Լաբորատոր աշխատանք 1 — ՆԱԽԱԼԱԲՈՐԱՏՈՐ ԹԵՐԹԻԿ
**Տվյալների թերթիկից դեպի տվյալներ** · 2-րդ շաբաթ · Միկրոէլեկտրամեխանիկական համակարգեր և տվիչներ

> **ԱՅՍ ԼԱԲՈՐԱՏՈՐ ԱՇԽԱՏԱՆՔՈՒՄ ԾՐԱԳՐԱՎՈՐՈՒՄ ՉԻ ՊԱՀԱՆՋՎՈՒՄ։**
> Սալերը նախապես ծրագրավորված են։ Տվիչը կառավարելու եք հաջորդական կապի
> վահանակից՝ մուտքագրելով տվյալների թերթիկից **ինքնուրույն** որոշված ռեգիստրների
> հասցեներն ու արժեքները։ Այնուհետև հում կոդերը **ինքնուրույն** փոխակերպելու եք
> ֆիզիկական մեծությունների միավորների՝ թղթի վրա կամ էլեկտրոնային աղյուսակում։
> Ծրագրային գործիքաշար օգտագործելու կամ որևէ ծրագիր կազմարկելու անհրաժեշտություն չկա։
>
> Ներկառուցված ծրագրերի մշակումը կսկսեք կիսամյակի ավելի ուշ փուլում՝
> միկրոկառավարիչներին նվիրված պարապմունքներից հետո։

> **ԱՅՍ ԹԵՐԹԻԿԸ ԼԱԲՈՐԱՏՈՐ ԱՇԽԱՏԱՆՔԻՆ ՄԱՍՆԱԿՑԵԼՈՒ ՆԱԽԱՊԱՅՄԱՆ Է։**
> Այն ներկայացրեք լրացված, տպագիր տարբերակով և ձեր ձեռագրով։ Դասախոսը կամ
> լաբորանտը փորձասեղանի մոտ ստորագրում է D բաժինը։ **Առանց ստորագրության սալին
> սնուցում մի՛ միացրեք։** Սխալ սնուցման լարումը կամ տրամաբանական մակարդակը կարող է
> վնասել բաղադրիչը՝ նախքան սխալը նկատելը։

Անուն, ազգանուն՝ ______________________________  Խումբ՝ ______  Ամսաթիվ՝ __________

## A · Պարտադիր ընթերցանություն

1. Սույն թերթիկը՝ ներառյալ I²C-ի համառոտ նկարագրությունը (F բաժին) և վահանակի
   հրամանների տեղեկատուն (G բաժին)։
2. **ST ISM330DHCXTR** տվիչի տվյալների թերթիկը (iNEMO վեցառանցք իներցիալ չափման
   միավոր)։ Անհրաժեշտ բաժիններն են՝ ելուստների նկարագրությունը, էլեկտրական
   բնութագրերը (սնուցման և տրամաբանական մակարդակները), ռեգիստրների քարտեզը և
   զգայունության աղյուսակը։ Փաստաթուղթը ներբեռնեք st.com կայքից և առաջին էջից
   գրանցեք խմբագրության համարը․ այն պահանջվելու է աշխատանքի ընթացքում։
3. Ձեր սալի օգտագործողի ձեռնարկի՝ ելուստների դասավորության էջը։ Որոշեք, թե որ
   ֆիզիկական ելուստներով է իրականացվում I²C1 կապը։

I²C հաղորդակցությունը դեռևս չի ներկայացվել դասախոսության ընթացքում։ Այն
քննարկվելու է 3-րդ դասախոսությունում, իսկ ամբողջական տեսությունը՝ 13-րդ
դասախոսությունում։ F բաժինը պարունակում է այս աշխատանքի համար անհրաժեշտ ամբողջ
տեղեկությունը։

## B · Տվյալների արտագրում տվյալների թերթիկից *(էջերի համարները պարտադիր են)*

Այս աղյուսակի լրացումը նախալաբորատոր աշխատանքի հիմնական մասն է։ Գրանցված
արժեքներն օգտագործելու եք փորձասեղանի մոտ՝ հաջորդական կապի վահանակում։

| № | Պարամետր | Ձեր պատասխանը | Էջ |
|---|---|---|---|
| 1 | Սնուցման լարում V_DD, նվազագույն–առավելագույն | | |
| 2 | Մուտք/ելքի սնուցման լարում V_DDIO, նվազագույն–առավելագույն (եթե առանձին է) | | |
| 3 | Ցանկացած ելուստի բացարձակ առավելագույն թույլատրելի լարում | | |
| 4 | Սարքի 7-բիթանոց I²C հասցեն և այն ընտրող ելուստը | | |
| 5 | Սարքի նույնականացման ռեգիստրը՝ **հասցեն** և **ակնկալվող արժեքը** | | |
| 5բ | Օգտագործվող տվյալների թերթիկի խմբագրության համարը | | — |
| 6 | Արագաչափի կառավարման ռեգիստրի հասցեն | | |
| 7 | Լրիվ չափման տիրույթը սահմանող բիթային դաշտը և դրա **կոդավորումը** | | |
| 8 | Ելքային տվյալների հաճախությունը սահմանող բիթային դաշտը և դրա կոդավորումը | | |
| 9 | Զգայունությունը (mg/LSB)՝ **յուրաքանչյուր** ընտրելի չափման տիրույթի համար | | |
| 10 | Արագաչափի ելքային տվյալների առաջին ռեգիստրի հասցեն | | |
| 11 | Ելքային տվյալների ձևաչափը՝ բիթերի քանակ, նշանային ներկայացում և բայթերի հերթականություն | | |

**7-րդ կետը պահանջում է հատուկ ուշադրություն։** Մի՛ ենթադրեք, որ չափման տիրույթի
կոդերն աճում են սպասվող հերթականությամբ։ Օգտվեք տվյալների թերթիկի աղյուսակից։ Այս
կետում ենթադրությամբ ընտրված արժեքը հաճախ հանգեցնում է կայուն, կրկնելի, սակայն
սխալ չափումների։

## C · Նախալաբորատոր հաշվարկներ

**C1.** Ձեր սալի մուտք/ելքի տրամաբանական մակարդակը 3.3 V է։ Տվիչի V_DDIO-ի
առավելագույն արժեքը գրանցել եք B2 կետում։ Ի՞նչ տեղի կունենա, եթե տվիչը միացվի
5 V տրամաբանական մակարդակով աշխատող սալին, և ո՞ր ելուստը կարող է վնասվել առաջինը։

<br><br>

**C2.** Տվիչը կարգավորելու եք **±2 g** չափման տիրույթի համար։ B9 կետի պատասխանի
հիման վրա նշեք մեկ նվազագույն նշանակալի բիթի (LSB) արժեքը mg-ով և 16-բիթանոց
ամբողջ տիրույթը՝ g-ով։

<br><br>

**C3.** Կազմեք այն բայթը, որը պետք է գրանցել արագաչափի կառավարման ռեգիստրում
(B6)՝ **±2 g** չափման տիրույթ և մոտ **100 Hz** ելքային տվյալների հաճախություն
ստանալու համար։ Ներկայացրեք բիթային դաշտերը։

```
    բիթ  7   6   5   4   3   2   1   0
        ┌───┬───┬───┬───┬───┬───┬───┬───┐
        │   │   │   │   │   │   │   │   │      =  0x______
        └───┴───┴───┴───┴───┴───┴───┴───┘
          └──── ODR ────┘ └─FS─┘
```

Փորձասեղանի մոտ այս արժեքը մուտքագրելու եք `w <reg> <val>` հրամանով։ Տվիչը
ընդունում է նաև սխալ կարգավորումը և կարող է հաղորդել թվացյալ վստահելի, բայց սխալ
տվյալներ։ Ուստի նախապես ստուգեք բիթային կոդավորումը։

**C4.** Տվիչը հորիզոնական և անշարժ տեղադրված է փորձասեղանին, իսկ Z առանցքն
ուղղված է դեպի վեր։ Կանխատեսեք X, Y և Z առանցքներից սպասվող հում ամբողջ թվերը
±2 g տիրույթի դեպքում։ Ներկայացրեք հաշվարկը։

  Z՝ ____________   X՝ ____________   Y՝ ____________

**C5.** Վահանակը տպում է հետևյալ վեց բայթը՝ նախ կրտսեր բայթը, X, Y, Z
հերթականությամբ․

```
  բայթեր՝ 00 00   30 FC   00 40
```

Կազմեք երեք նշանով 16-բիթանոց ամբողջ թվերը և ±2 g տիրույթի համար դրանք
փոխակերպեք **mg**-ի։ Հաշվեք արագացման ընդհանուր մոդուլը։ Արդյո՞ք արդյունքը
իրատեսական է անշարժ տվիչի համար։

  X = ________ = ________ mg    Y = ________ = ________ mg
  Z = ________ = ________ mg    մոդուլ = ________ mg    իրատեսակա՞ն է՝ ______

**C6.** Ընտրեք օգտագործվող ելքային տվյալների հաճախությունը (ODR) և մեկ
նախադասությամբ հիմնավորեք ընտրությունը։ Չափվում է ստատիկ կողմնորոշում, ոչ թե շարժում։

  ODR՝ __________  Հիմնավորում՝ ________________________________________

## E · Միացման պլան *(գծեք այն․ հիշողությամբ մի՛ միացրեք)*

```
        ┌──────────────────┐                    ┌──────────────────┐
        │    Nucleo սալ    │                    │   տվիչի մոդուլ   │
        │  3V3 ........... │────────────────────│ VDD              │
        │  GND ........... │────────────────────│ GND              │
        │  I2C1_SDA (D14)  │────────────────────│ SDA              │
        │  I2C1_SCL (D15)  │────────────────────│ SCL              │
        └──────────────────┘                    └──────────────────┘
                             վերքաշող դիմադրություններ՝ ______ kΩ դեպի ______
```

**D14/D15 ելուստների համապատասխանությունը ստուգեք հենց ձեր սալի օգտագործողի
ձեռնարկով։** Նշված դասավորությունը սովորաբար կիրառվում է Nucleo-64 սալերի Arduino
միակցիչում, սակայն տարբերակները կարող են տարբերվել։ Մեկ այլ խմբի հաջողված
միացումը բավարար հաստատում չէ։

Տվիչների միջերեսային մոդուլների մեծ մասն արդեն ունի վերքաշող դիմադրություններ։
Նոր դիմադրություններ ավելացնելուց առաջ ստուգեք սալը․ զուգահեռ միացված երկու
դիմադրությունների խմբերը կրկնակի նվազեցնում են համարժեք դիմադրությունը և կարող են
խափանել հաղորդուղու աշխատանքը։ Ի՞նչ պարզեցիք ստուգման արդյունքում։

## F · I²C-ն մեկ էջում *(այս աշխատանքի համար անհրաժեշտ ամբողջ տեղեկությունը)*

**Երկու գիծ, բազմաթիվ սարքեր։** `SCL`-ը տակտային ազդանշանի գիծն է, որը մշտապես
կառավարում է կառավարիչը՝ ձեր Nucleo սալը։ `SDA`-ն տվյալները փոխանցում է երկու
ուղղությամբ։ Բոլոր սարքերն օգտագործում են գծերի նույն զույգը։

**Բաց դրենով ելքեր․ վերքաշող դիմադրությունները պարտադիր են։** Սարքերը կարող են
գիծը միայն միացնել ցածր տրամաբանական մակարդակին։ Բարձր մակարդակն ապահովում է
V_DDIO-ին միացված դիմադրությունը․ 100 kHz հաճախության դեպքում սովորաբար կիրառվում
է 4.7 kΩ։ **Առանց վերքաշող դիմադրության հաղորդուղու գծերը մնում են ցածր
մակարդակում, և հաղորդակցությունը չի աշխատում։** Սա առաջին աշխատանքի ամենատարածված
անսարքությունն է։ Այդ դեպքում վահանակի `scan` հրամանը սարքեր չի հայտնաբերի։

**Հասցեավորում։** Յուրաքանչյուր սարք ունի 7-բիթանոց հասցե։ Տվիչի ելուստներից մեկը
սովորաբար հնարավորություն է տալիս ընտրելու երկու հասցեներից մեկը, որպեսզի նույն
տեսակի երկու սարք կարողանան աշխատել մեկ հաղորդուղում։ Վահանակում մուտքագրելու եք
7-բիթանոց հասցեն։ Վահանակը ցուցադրում է նաև 8-բիթանոց տարբերակը, քանի որ հետագայում
օգտագործվող որոշ ծրագրային գրադարաններ պահանջում են հասցեն մեկ բիթով ձախ շեղել։
Այս աշխատանքի ընթացքում 8-բիթանոց տարբերակը չի օգտագործվում։

**Ռեգիստրի ընթերցումը** բաղկացած է երկու փոխանցումից․ նախ գրվում է ռեգիստրի
հասցեն, ապա ընթերցվում են տվյալները։ Վահանակը երկու գործողությունն էլ իրականացնում
է `r` հրամանով։

**Փաթեթային ընթերցում։** Եթե ելքային վեց բայթը ընթերցվի առանձին գործողություններով,
X առանցքի արժեքը կարող է պատկանել մի նմուշի, իսկ Z առանցքի արժեքը՝ հաջորդին։ Այդ
դեպքում ստացվում է տարբեր նմուշներից կազմված, բայց արտաքուստ իրատեսական չափում։
Վահանակի `dump` հրամանը բոլոր վեց բայթերը կարդում է **մեկ փոխանցմամբ** և նույն
նմուշից։

**Նշանով 16-բիթանոց արժեքի կազմում։** Յուրաքանչյուր առանցքի արժեքը պահվում է երկու
8-բիթանոց ռեգիստրում։ Այս տվիչների ընտանիքում նախ փոխանցվում է կրտսեր բայթը, իսկ
թիվը ներկայացվում է **երկուսի լրացուցիչ կոդով**․

```
    արժեք = (ավագ_բայթ × 256) + կրտսեր_բայթ
    եթե արժեք ≥ 32768՝  արժեք = արժեք − 65536    ← այս քայլն ապահովում է բացասական նշանը
```

Եթե վերջին քայլը բաց թողնեք, դեպի ներքև թեքման մոտ −1500 արժեքի փոխարեն կարող եք
ստանալ մոտ +64000։ Վահանակը կատարում է այս միավորումը և տպում է ինչպես բայթերը,
այնպես էլ նշանով ամբողջ թիվը։ Դրանով կարող եք ստուգել C5 կետում կատարված ձեր
հաշվարկը։

**Թվային կոդերը ֆիզիկական մեծություններ չեն։** Նշանով ամբողջ թիվը դեռ արագացում
չէ։ Այն բազմապատկեք տվյալների թերթիկում նշված զգայունությամբ՝ օգտագործելով միայն
իրականում ընտրված չափման տիրույթին համապատասխանող տողը․

```
    a [mg] = հում կոդ × զգայունություն [mg/LSB]
```

Վահանակն այս փոխակերպումը **չի կատարում**։ Այն պետք է կատարեք ինքնուրույն․ սա
լաբորատոր աշխատանքի հիմնական նպատակներից է։

## G · Վահանակի հրամանների տեղեկատու *(սալերը նախապես ծրագրավորված են)*

Հաջորդական կապի տերմինալ՝ **115200 8N1**, նույն USB մալուխով, որով սնուցվում է սալը։
Եթե այլ բան նշված չէ, արժեքները մուտքագրվում են տասնվեցական ձևաչափով։

| Հրաման | Գործողություն |
|---|---|
| `help` | ցուցադրում է հրամանների ցանկը |
| `scan` | ցուցադրում է հաղորդուղում պատասխանող բոլոր սարքերը․ **ձեր առաջին ախտորոշիչ քայլը** |
| `addr 6B` | ընտրում է այլ 7-բիթանոց հասցեով սարք |
| `r 0F` | ընթերցում է մեկ ռեգիստր և արժեքը ցուցադրում տասնվեցական, տասնորդական ու երկուական ձևաչափերով |
| `r 10 4` | ընթերցում է հաջորդական չորս ռեգիստր (քանակը տասնորդական է) |
| `w 10 40` | `0x10` ռեգիստրում գրում է `0x40`, ապա հաստատման համար հետ է ընթերցում այն |
| `dump 28` | `0x28` հասցեից ընթերցում է վեց բայթ և կազմում երեք նշանով 16-բիթանոց արժեք |
| `log 28 200 50` | յուրաքանչյուր 50 ms-ը մեկ գրանցում է 200 նմուշ՝ CSV ձևաչափով․ տվյալները պատճենեք էլեկտրոնային աղյուսակ |

Վահանակը տպում է **միայն հում կոդերը**։ Այն չի ցուցադրում mg կամ m/s²։ Հաշվետվության
մեջ ներկայացված յուրաքանչյուր ֆիզիկական արժեք պետք է ստացվի ձեր հաշվարկով։

## H · Ներկայացվող նյութերը

1. Նշումներով միացման սխեման՝ E բաժնից, ճշտված ըստ իրականացված միացման։
2. Ռեգիստրների աղյուսակը՝ յուրաքանչյուր գրված ռեգիստրի հասցեով, արժեքով և ընտրության
   **հիմնավորմամբ**։
3. Տվյալների կարճ գրանցում՝ հում կոդերով և ձեր հաշվարկած ՄՄ (SI) արժեքներով՝ նշված
   չափման միավորներով։
4. 1 g արդյունքի իրատեսականության ստուգման ապացույցը։
5. Մեկ նախադասությամբ պատասխան․ 1-ին դասախոսության չափման շղթայի ո՞ր փուլն եք
   իրականացրել այս աշխատանքում։

> **ԱՅՍ ԼԱԲՈՐԱՏՈՐ ԱՇԽԱՏԱՆՔՈՒՄ ԿԿԱԶՄԱՐԿԵՔ ԵՎ ԿԾՐԱԳՐԱՎՈՐԵՔ ՍԱԼԸ — ՄԵԿ ԱՆԳԱՄ, ԲՈԼՈՐԴ ՄԻԱՍԻՆ։**

> ընթացքում ծրագրային գործիքաշարին խմբով նվիրված միակ քսան րոպեն են։

> ժամանակը․ C բաժինը տանը կատարվող քսան րոպե հաշվարկ է, որը փոխարինում է
> փորձասեղանի մոտ մեկ ժամ շփոթությանը։ Առանց դրա եկած խումբը չի ավարտի աշխատանքը։

## C · Նախալաբորատոր հաշվարկներ

Ցույց տվեք ընթացքը։ Առանց ընթացքի ներկայացված արժեքը չի գնահատվում՝ ո՛չ այստեղ,
ո՛չ հաշվետվությունում։

### C1 · Քվանտացման քայլը և դրա աղմուկը

±2 g տիրույթում և 16 բիթի դեպքում․

```
չափման լրիվ տիրույթ = ____________ mg     ԿՆԲ = տիրույթ / 2^16 = ____________ mg

քվանտացման աղմուկ  σ_q = ԿՆԲ / √12 = ____________ mg
```

### C2 · Աղմուկը, որը պետք է չափեք հինգ տարբեր հաճախությունների դեպքում

Թողունակությունը `ODR/2` է։ Աղմուկը՝ `խտություն × √թողունակություն`։ Օգտագործեք
B2-ի **max.** խտությունը, քանի որ հենց այդ արժեքն է երաշխավորված ձեր սարքի համար։

| ODR (Հց) | `CTRL1_XL` ±2 g-ի, LPF2 անջատված | BW = ODR/2 (Հց) | σ = խտություն × √BW (mg) | σ՝ ԿՆԲ-ով | կորած բիթեր = log₂(σ/ԿՆԲ) | արդյունարար բիթեր |
|---|---|---|---|---|---|---|
| 26 | | | | | | |
| 52 | | | | | | |
| 104 | | | | | | |
| 208 | | | | | | |
| 416 | | | | | | |

**C2ա** — Քանի՞ անգամ է փոխվում σ-ն ODR-ի յուրաքանչյուր կրկնապատկման դեպքում։
Կանխատեսեք բանաձևից՝ *նախքան* տողերը հաշվարկելը, ապա ստուգեք, որ ձեր տողերը

### C3 · Զտիչը, որը կկիրառեք հետո

Անկախ նմուշների **N նմուշով սահող միջինացումը** նվազեցնում է պատահական աղմուկը
`√N` անգամ և մոտավորապես նույն չափով նվազեցնում է թողունակությունը։

**C3ա** — Գրանցում եք 416 Հց հաճախությամբ և միջինացնում N = 4 նմուշ։ Ի՞նչ σ եք
կանխատեսում։

`σ(416 Հց) / √4` = ____________ mg

## G · Էլեկտրոնային աղյուսակի տեղեկատու  *(վերլուծության համար անհրաժեշտ ամեն ինչ)*

Անհրաժեշտ է հինգ գործողություն։ LibreOffice-ում, Excel-ում և Google Sheets-ում
դրանք նույնն են։ Եթե `raw_x`-ը C սյունակում է՝ 2-րդ տողից 2001-րդ տողը․

| Ինչ է պետք | Բանաձև |
|---|---|
| միջինը՝ կոդերով | `=AVERAGE(C2:C2001)` |
| միջին քառակուսային շեղումը՝ կոդերով | `=STDEVP(C2:C2001)` — կամ `STDEV.P`, նույնն են |
| որևէ մեկը՝ mg-ով | բազմապատկեք B4 զգայունությամբ |
| σ-ն՝ արտահայտված ԿՆԲ-ով | `=STDEVP(C2:C2001)` — արդեն ԿՆԲ-ով է, քանի որ կոդը հենց ԿՆԲ է |
| 4 նմուշով սահող միջինացում | `F5` վանդակում՝ `=AVERAGE(C2:C5)`, ապա լրացրեք ներքև |
| առաջին կարգի ցածր հաճախությունների զտիչ, α = 0.25 | `G2`-ում՝ `=C2`; `G3`-ում՝ `=G2+0.25*(C3-G2)`, լրացրեք ներքև |
| նմուշառման իրական քայլը | `=(B2001-B2)/1999` — B սյունակը `t_ms` է |

Երկու թակարդ, որոնք ամեն տարի խմբերին արժենում են մեկ ժամ․

1. **Ամբողջ ընտրանքի, ոչ թե մասնակի ընտրանքի շեղումը՝ `STDEVP` (կամ `STDEV.P`), ոչ
   թե `STDEV`։** Ձեզ մոտ ամբողջ գրանցումն է, ոչ թե դրա մի մասը։ 2000 կետի դեպքում
   տարբերությունը 0.03 % է, ուստի եզրակացությունը չի փոխվի, բայց նշեք, թե որն
   օգտագործեցիք։
2. **σ-ն կոդերով արդեն σ է ԿՆԲ-ով։** Կոդը *հենց* ԿՆԲ է։ Զգայունությամբ
   բազմապատկեք **միայն մեկ անգամ**՝ միլի-*g* ստանալու համար։ Խմբերը պարբերաբար
   երկու անգամ են բազմապատկում և ստանում մեկ կոդից փոքր արժեք, ինչը հնարավոր չէ։
   Եթե ձեր σ-ն ±2 g-ում 0.061 mg-ից փոքր է, հենց այդ սխալն եք թույլ տվել։
